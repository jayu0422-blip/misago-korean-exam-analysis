- 대상 시험: 2025.04.28 / 2025.06.30 / 2025.10.01 / 2025.12.11 / 2026.04.28 / 2026.06.30
- 과목: 공통국어1·2 (2022 개정)
- 정리: 김영하

> **저작권 표기**
> `img/`와 `원본/`의 시험지 자료는 미사고등학교의 저작물입니다. 이 저장소는 강사 간 출제 경향 공유를 목적으로 한 자료이며, 상업적 이용이나 재배포를 위한 것이 아닙니다. 학교의 요청이 있으면 즉시 내리겠습니다.

## 확인된 사실

- 6회 전부 **선택형 24문항 100점**, 서답형 없음 (26-1 기말 학교 공식표에 `서답형만점 0.00` 명시)
- 화작 2문항 + 독서 2~3문항(15~21점)이 **그해 학력평가 지문**에서 옴
  → 2026년 3월 학평과 26-1 중간 사이에서 지문 동일성 확인 (호작도 발표 / 골격근·지레)
- 문법은 학기·차수별 단원 고정 — 1-1중간 음운 / 1-1기말 문법요소 / 1-2중간 중세국어 / 1-2기말 한글맞춤법
- 배점은 3.7~4.6점만 존재, 평균 4.17점
- 1학기 시험은 전년도 같은 차수와 작품이 겹침 (중간 7편 중 3편, 기말 7편 중 1편)

## 검증

초판 작성 후 10인 검증단이 원본을 재대조해 **81건 제기 → 34건 확정 정정**했습니다. 주요 정정 사항은 `노트_원자료.md` 맨 끝의 정정 로그에 있습니다.

- 25-2 기말 18번 배점 4.1 → **4.4** (붉은 채점펜에 가려진 오독). 이로써 6회 전부 합계 정확히 100.0
- 「왜려설」 26년판은 발췌 확대가 아니라 **축소**
- 「배반의 여름」은 26년판이 더 김 (앞부분 줄거리 + 풀장 도입부 추가)
- 서정주 작품명은 「외할머니의 뒤안 **툇마루**」, 갈래는 수필이 아니라 **산문시**
- 표준발음법 조항은 11개가 아니라 **12개**
